# Guion Demo Comercial - Sentinel Express

## Apertura
*Presentar Sentinel Express como una herramienta de apoyo para revisión fiscal de XML CFDI, no como dictamen fiscal definitivo.*

**Mensaje base:**
“Sentinel Express ayuda a convertir XMLs fiscales dispersos en información revisable, auditable y exportable a Excel para detectar riesgos más rápido.”

## Problema del cliente
Enfocarse en resolver los siguientes puntos de fricción:
* Revisión manual lenta de cada factura.
* Muchos XMLs dispersos y desorganizados.
* Riesgo de errores matemáticos en importes y totales.
* Dificultad técnica para revisar el complemento Carta Porte.
* Dificultad para detectar y conciliar Complementos de Recepción de Pagos (REP).
* La necesidad imperativa de exportar la información a Excel para auditoría contable.

## Qué sí puede demostrarse
Durante esta demo, **solo** se prometerá lo siguiente:
* Procesamiento de CFDI 4.0 de ingresos.
* Extracción de REP 2.0.
* Extracción de Carta Porte.
* Alertas EFOS/listas negras **como indicador de riesgo** (no como resolución oficial).
* Exportación a Excel validada.
* Procesamiento masivo controlado.
* Detección de errores estructurales y diferencias matemáticas básicas.

## Qué NO debe prometerse
Por ningún motivo prometer o garantizar:
* Producción completa y desatendida.
* Emisión de un dictamen fiscal válido.
* Validación oficial ante los servidores del SAT en tiempo real.
* Sustitución del trabajo del contador o asesor legal.
* Cumplimiento fiscal garantizado al 100%.
* Procesamiento certificado de CFDI 3.3.
* Egresos (Notas de crédito) certificados.
* Traslados certificados.
* Nómina certificada.
* Tasa 0 certificada.
* Exentos certificados.
* Retenciones certificadas.
* REP cruzado automáticamente contra toda la cadena histórica PPD.

## Recorrido sugerido de demo
1. **Explicar carga de XMLs:** Demostrar cómo se arrastran los archivos locales sin comprometer la seguridad.
2. **Cargar muestra controlada:** Usar un lote pre-validado de XMLs de prueba.
3. **Mostrar tablero:** Explicar los indicadores generales de resumen.
4. **Mostrar XML correcto:** Visualizar una factura estándar procesada exitosamente.
5. **Mostrar XML con alerta:** Evidenciar cómo el sistema levanta la mano ante un descuadre.
6. **Mostrar Carta Porte:** Enseñar el desglose de transporte y mercancías.
7. **Mostrar REP:** Mostrar la vinculación del pago con los documentos amparados.
8. **Mostrar alerta EFOS como riesgo:** Dejar claro que es una advertencia preventiva para el contador.
9. **Exportar Excel:** Descargar el archivo final consolidado.
10. **Explicar uso del Excel:** Describir cómo el contador usaría este archivo para buscar inconsistencias y conciliar con el ERP.

## Cierre
"Para que experimentes el valor de tener toda tu información tabulada en segundos, te invitamos a correr un **piloto controlado** con una muestra de tu propia facturación reciente." *(No invitar a producción masiva inmediata).*
