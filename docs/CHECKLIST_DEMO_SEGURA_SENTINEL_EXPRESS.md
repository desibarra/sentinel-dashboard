# Checklist de Demo Segura - Sentinel Express

*Para uso exclusivo del presentador. Validar cada punto antes, durante y después de la demostración.*

- [ ] Confirmar que la app levanta correctamente en el entorno de demostración.
- [ ] Usar solo XMLs autorizados y pre-validados.
- [ ] Confirmar previamente que el Excel exporta sin errores en la máquina local.
- [ ] No usar XMLs sensibles del prospecto o de terceros sin autorización explícita.
- [ ] **NO decir** “certificado por SAT”.
- [ ] **NO decir** “garantiza cumplimiento fiscal”.
- [ ] Aclarar permanentemente los límites técnicos de la herramienta.
- [ ] Registrar activamente todas las preguntas y dudas del prospecto.
- [ ] Documentar cualquier error detectado si se procesa un XML inesperado.
- [ ] Cerrar la demo estrictamente ofreciendo un **piloto controlado**, nunca un pase a producción masiva.
